# Bundled fonts

The Slint interface embeds DejaVu Sans regular (`DejaVuSans.ttf`) and bold
(`DejaVuSans-Bold.ttf`) for consistent Latin, Hebrew, Arabic, and filename
rendering, plus DejaVu Sans Mono (`DejaVuSansMono.ttf`) for device names such as
`nvme0n1p1`. All are covered by `DejaVu-LICENSE.txt`, which packaging includes.

Interface icons are SVG files in `ui/icons/`.
